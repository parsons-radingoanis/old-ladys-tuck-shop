# Old Lady's Tuck Shop

## About the Project

Old Lady's Tuck Shop is a console-based Java application developed in 2024 during my first year of studying Computer Science.

The application simulates basic tuck shop operations, allowing a cashier to select products, process customer payments, calculate change and generate receipts.

This was one of my early programming projects, where I applied the Java programming concepts I was learning at the time.

## Features

- Display available products and prices.
- Allow customers to select products.
- Check product stock availability.
- Process customer payments.
- Calculate and display change.
- Generate customer receipts (till slips).
- Display shop summaries and product sales information.
- Menu-driven console interaction.

## Technologies and Concepts

- **Language:** Java
- Scanner for user input
- Arrays
- Methods
- Loops
- Conditional statements
- Switch statements
- DecimalFormat

## Running the Application

1. Clone or download this repository.
2. Open the project in a Java IDE, such as NetBeans.
3. Locate the `TuckShopApp.java` file.
4. Run the application.
5. Follow the instructions displayed in the console.
